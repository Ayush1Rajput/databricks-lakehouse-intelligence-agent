# Databricks Lakehouse Intelligence Agent

An MCP-powered, governed Natural-Language Business Analytics Agent built on Databricks.

## Objective

The project allows users to ask business questions in natural language and receive answers based on governed data stored in the Databricks Lakehouse.

## Core Architecture

User
  ↓
LLM / Agent
  ↓
MCP Client
  ↓
MCP Server
  ↓
Databricks
  ↓
Unity Catalog + Delta Lake + SQL Warehouse

## Dataset

Olist Brazilian E-Commerce Public Dataset
